What is it: A Departure Control System is the program that airlines use for checking in passengers and baggage, boarding passengers, and flight departure.

What does it do: This program helps airline ground staff see who still needs to be checked in, verify travel documents, see which passengers still need to be boarded, if all the baggage has been loaded into the aircraft, and whether the aircraft is ready to depart.

How does it do this: Concurrent flight and passenger information can be viewed by ground staff so everyone is on the same page.
